# Serviço de Catálogo

Mantém os recursos (laboratórios e equipamentos) disponíveis para reserva. Porta **3001**.

```bash
npm install
npm run dev   # Catálogo rodando em http://localhost:3001
```

Endpoints, exemplos de body e tabela de status: veja o [README principal](../README.md).
`node_modules` não deve ir ao repositório.
